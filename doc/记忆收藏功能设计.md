# 记忆收藏功能设计

## 范围

收藏覆盖记忆模块中的四类可复用资产：知识、操作、数据、文档。用户可在详情抽屉中收藏或取消收藏，并可在各自列表中选择“全部 / 已收藏 / 未收藏”。收藏筛选与关键词、类型、日期和分页参数共同生效。

## 交互约定

- 详情抽屉底部展示带星标图标的“收藏”按钮；收藏后切换为暖黄色“已收藏”，再次点击取消。
- 收藏更新期间禁用按钮并展示“更新中…”，避免重复提交。
- 列表筛选使用统一的“收藏状态”下拉框。切换后立即回到第一页并清除当前选中详情。
- 若用户在“已收藏”或“未收藏”筛选结果中改变当前记录的收藏状态，该记录立即退出当前结果集并关闭详情。
- 收藏请求失败时保留原状态，并通过页面状态消息反馈失败原因。

## 本地契约

统一写接口：

```http
PUT /api/memory-favorites/{resource_kind}/{resource_id}
Content-Type: application/json

{"is_favorite":true}
```

`resource_kind` 只允许：`knowledge`、`operation`、`data`、`document`。接口幂等；目标不存在或已删除时返回 404，不生成孤立收藏记录。

知识、操作、数据、文档的列表接口新增可选查询参数 `favorite=true|false`。不传参数时保持原有行为。列表项与详情响应都返回 `is_favorite`。

## 存储与生命周期

收藏状态存放在本地 SQLite `memory_favorites` 表中，以 `(resource_kind, resource_id)` 为联合主键。表中只保存已收藏记录，未收藏是缺省状态，因此不会为历史数据执行批量回填。

- 删除知识、操作、数据或文档时同步清理收藏记录。
- 数据语义重提炼发生记录合并时，收藏会迁移到最终保留的数据记录。
- 完整本地备份包含收藏表；恢复后四类收藏状态保持不变。

## 验证范围

- 存储层：幂等写入、资源类型隔离、非法类型和不存在资源校验。
- API：三类 Bake 资产与数据的详情状态、已收藏/未收藏列表筛选、错误状态码。
- UI：四个详情页的收藏按钮、四个列表的收藏状态筛选、统一请求参数映射。
- 备份：四类收藏状态完整导出并恢复。
- 回归：Rust 全量测试、前端收藏相关测试、TypeScript 与 Vite 生产构建、Rust 格式检查。
