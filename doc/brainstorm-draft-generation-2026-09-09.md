# 脑暴卡片：先生成一版

脑暴探索中的当前问题卡片增加“先生成一版”，无须答完当前题或等待模型收敛。点击后沿用现有 Agent 文档生成流程，传入原始要求、已保存的脑暴简报与现有正文（如有）；当前未提交的选项或自定义答案不写入简报。

## 行为边界

- 不调用脑暴 `answer`、`skip` 或 `finish`，不改变脑暴阶段、版本、原问题与已答历史。
- 生成指令要求未确定事项保留待确认，不将未答题选项写成用户决定。
- 生成期间展示只读的脑暴依据，完成后暂停问题交互；只有明确点击“继续脑暴”后才恢复原题。恢复已有正文的历史会话默认暂停。
- 失败可重试；恢复无正文的失败历史时也建立只读快照，避免重复问题与生成入口。
- 简报有未保存编辑时先提示保存；生成期间防重复提交，终止后禁止生成。
- Agent 接口不可用时，携带脑暴简报的请求不降级到缺失该上下文的旧生成接口，保留已有内容供重试。
