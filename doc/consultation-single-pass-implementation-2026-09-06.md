# 咨询默认检索与单次答案推理落地

2026-09-06。按用户最终确认的标准 RAG 方案实施，不增加批量审查推理。

## 行为

- 悬浮与普通咨询默认检索，当前材料存在或模型判断 false 均不再关闭检索；用户明确禁止检索时保留例外。
- 咨询路由不再调用意图模型，原始问题直接形成检索查询。流式生成总是复用第一次候选结果，包括非悬浮入口；成功咨询只有一次答案模型调用。
- 生成输入先放用户原始需求与本次材料，再放“候选历史记忆（可全部忽略）”。系统规则明确关键词相似不代表相同对象，允许零采用，不得根据历史改写用户问题。
- 删除强制“用户问题理解/关键依据/可复制文本”模板，不再要求模型扩写简单问题。
- 通用问题先给通用定义；内部阈值、业务规则和旧数据必须限定来源与适用范围，不能充当通用标准或当前现状。
- 模型以本次候选编号 [M1] 等标注实际使用的记忆。代码验证编号存在，渲染原资料链接；未知编号移除，流式分片中的未完成标记暂缓展示。
- 生成后的补链接与“前三个候选链接替换答案”不再执行。最终 API 与历史只展示实际引用，本次截图/输入仍单独保留。
- 内部候选集合与 cited_contexts 分开。候选仍在本地 prompt_used 中保留，便于诊断；references-only API 的语义不变。

## 限制

编号合法只证明引用来自本次候选，不能证明语义上相关或历史事实准确。本方案没有独立模型审查，模型仍可能误采用或遗漏引用；用真实故障样本持续评测。资料未进入候选池的召回覆盖问题另行处理，不以引用逻辑修复宣称解决。
