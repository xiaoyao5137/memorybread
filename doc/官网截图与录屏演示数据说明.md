# 官网截图与录屏演示数据

`scripts/seed-demo-data.py` 会向 MemoryBread 本地 SQLite 写入一套前后连贯的演示数据，故事主线为“产品经理筹备 AI 会议助手 2.0 发布”。演示内容不包含真实用户、公司或业务数据。

## 写入数据

在 `MemoryBread` 仓库下执行：

```bash
python3 scripts/seed-demo-data.py
```

默认写入 `~/.memory-bread/memory-bread.db`，并先在 `~/.memory-bread/backups/` 创建 SQLite 在线备份。脚本可重复执行：每次只替换自己生成的演示记录，不会删除用户真实数据。

每次会生成一套数量稳定、标题不重复的数据：

- 48 条采集记录；
- 24 条时间线；
- 24 条知识；
- 24 个文档，其中包含 5 份已确认会议纪要；
- 24 个操作手册；
- 24 组数据记录；
- 24 条咨询记录；
- 24 条创作记录。

演示指标统一保存为 `work_memory` 本地工作数据快照，不使用虚拟网页报表地址。这样在录制周报创作时，数据检索会直接使用已验证的本地快照，不会对 `demo.memorybread.local` 占位地址触发无意义的网页爬取；真实用户添加的可访问报表仍按产品规则进行受控刷新与 AX/DOM 证据校验。

写入后单独校验：

```bash
python3 scripts/seed-demo-data.py --verify
```

只移除这套演示数据：

```bash
python3 scripts/seed-demo-data.py --remove
```

临时测试库可指定路径：

```bash
python3 scripts/seed-demo-data.py --db /path/to/memory-bread.db --no-backup
```

## 四个拍摄场景

### 1. 时间线详情

进入“记忆 → 时间线”，选择：

- `敲定灰度发布指标与首周观察计划`：适合展示时间线摘要、详情、关键片段与来源采集。
- `回看用户访谈，确认会后纪要速度是首要诉求`：适合为后续“找回资料”场景做铺垫。

### 2. 知识与文档详情

进入“记忆 → 知识”，选择 `用户把“快速得到可直接分享的纪要”视为首要价值`，展示系统从工作记录中沉淀出验收口径。

再进入“记忆 → 文档”，选择 `AI 会议助手 2.0 产品设计方案`，展示文档结构、写作风格、正文与来源时间线。

还可以进入“记忆 → 操作”，选择 `产品研究操作手册`，展示触发关键词、五步操作流程和关联知识；进入“记忆 → 数据”，选择 `纪要生成质量看板`，展示摘要、指标值、数据时效与来源时间线。

### 3. 咨询找回看过的资料

进入“咨询 → 咨询记录”，打开：

> 我记得用户访谈里提到“会后很快拿到能直接发出去的纪要”，具体在哪份资料？当时定的验收标准是什么？

记录会恢复完整答案和 3 条参考资料，可继续点击资料跳转到文档、知识或时间线。

### 4. 创作周报与产品设计方案

进入“创作 → 创作记录”，列表最前面提供 5 条完整的多 Agent 周报：

- `AI 会议助手 2.0｜产品研发周报`
- `AI 会议助手 2.0｜灰度增长与用户反馈周报`
- `AI 会议助手 2.0｜质量与性能专项周报`
- `AI 会议助手 2.0｜商业化与客户成功周报`
- `AI 会议助手 2.0｜管理层项目周报`

建议优先打开产品研发周报或管理层项目周报。每条记录都完整展示：

1. 数据检索 Tool 与记忆搜索 Tool 并行启动；
2. 数据检索召回 4 个本周数据来源；
3. 记忆搜索召回 3—4 份已确认会议纪要；
4. 数据分析 Agent 输出指标判断；
5. 章节扩写 Agent 补齐周报章节；
6. 文字润色 Agent 统一表达；
7. 内容质检 Agent 检查事实、数字、结构和行动项并通过质量门禁。

周报正文包含本周结论、核心数据表、数据分析、会议决策、本周已完成事项、风险和下周计划。打开底部“参考资料”可查看会议纪要，打开“参考数据”可查看指标快照及来源。

产品设计方案仍可打开：

- `基于访谈、范围评审、技术方案和交互原型，撰写《AI 会议助手 2.0 产品设计方案》……`

这些记录都包含完整 Markdown 文档、参考资料、对话记录和 Agent 执行轨迹，适合分别录制“多 Agent 周报生成”与“方案生成”镜头。

## 拍摄建议

- 时间线和知识先拍，咨询再演示“从历史工作中找回”，创作最后展示“用记忆生成新交付物”。
- 咨询页打开“参考资料”，创作页打开“参考资料”，更容易表达 MemoryBread 与普通聊天工具的区别。
- 演示数据使用近期相对日期，重新执行脚本后会自动刷新到当前日期附近。
