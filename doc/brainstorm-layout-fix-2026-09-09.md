# 脑暴对话与思路树布局调整

## 调整

- 移除主脑暴问题卡片中重复展示的全部历史决定，历史选择继续保留在左侧可编辑简报与思路树中。上一题、下一题和修改历史答案仍可用。
- 新问题、会话恢复及历史回看时，将右侧定位到题目开头；简报打开时从顶部展示，避免沿用正文的滚底行为。
- 思路树短内容按自然高度展示，长内容默认按窗口高度限制预览区域；节点随左栏宽度换行，深层缩进封顶，避免横向越界。
- 支持展开完整树及顶部、底部收起入口。点击节点定位到详情，详情提供父问题和所属分支；展开收起保留草稿与选择，不写入业务状态。
