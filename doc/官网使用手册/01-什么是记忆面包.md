# 什么是记忆面包？

记忆面包是一款本地优先的 AI 工作记忆助手。它会在你授权的范围内记录工作现场，把零散的浏览、阅读、编辑和创作过程整理成可检索、可理解、可复用的长期记忆。

它要解决的不是“再多一个聊天窗口”，而是工作上下文不断流失的问题：看过的页面难以找回、做过的判断需要反复解释、写过的文档结构无法继续复用。记忆面包让今天发生过的工作，成为以后咨询、创作和复盘时可以调用的背景。

## 它如何工作

1. **采集**：自动记录授权范围内的屏幕内容与应用上下文，形成可回看的时间线。
2. **记忆**：从工作记录中提炼文档、知识、操作和数据，并建立来源关系。
3. **咨询**：根据时间、项目、应用或关键词找回相关背景，再回答你的问题。
4. **创作**：调用真实工作记忆和可复用 Skill，生成方案、总结、周报等文档初稿。
5. **任务与日记**：按计划自动生成结果，帮助你持续复盘和沉淀。
6. **集成与备份**：连接外部知识库与编码 Agent，并通过记忆包完成迁移或恢复。

## 为什么强调本地优先

采集、提炼、检索与创作默认在本机完成，本地模型不消耗云端 Token。敏感规则命中的内容会直接丢弃，只统计条数；应用黑名单可以让指定应用完全跳过采集。

“本地优先”不代表所有功能都不需要网络：账户、软件更新、任务奖励、可选云端模型和加密云端备份等能力会按需联网。云端记忆包会先在客户端加密，服务端不读取快照明文。

## 适合谁

- 经常需要写方案、总结、周报、PRD 或技术文档的职场人士
- 需要长期积累项目背景、决策和工作经验的个人工作者
- 希望让 AI 理解真实工作历史，而不是每次从零解释的人
- 重视本地存储、隐私控制和数据可迁移性的用户
- 希望让 Codex、Claude Code 等编码 Agent 续接项目上下文的开发者

## 主要入口

左侧导航分为三组：

- **工作**：咨询、创作、任务
- **知识库**：记忆、采集、日记、集成
- **系统**：模型、隐私、监控、设置

建议首次使用先阅读“快速开始”，完成系统授权与初始化，再从“采集”和“咨询”开始体验完整闭环。
