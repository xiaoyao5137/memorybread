# 四、联系我们

遇到问题时，建议先确认客户端版本、系统权限和本地服务状态，再选择合适的反馈渠道。

## 自助检查

1. 打开 **关于记忆面包**，确认当前版本。本文档内容基线对应 v0.1.2。
2. 打开 **设置**，检查运行状态和软件更新。
3. 打开 **监控**，确认采集、提炼、检索和创作相关服务是否正常。
4. 查看本使用手册对应功能页和官网 **更新记录**。
5. 重启应用后再次复现问题。

## 反馈渠道

- **使用手册**：<https://my.feishu.cn/wiki/Fqlrw0OwTiy3LOkLPpxcaeCOnBe>
- **GitHub 仓库**：<https://github.com/xiaoyao5137/MemoryBread>
- **问题与建议**：<https://github.com/xiaoyao5137/MemoryBread/issues>

## 提交问题时请提供

- 客户端版本和构建号
- macOS 版本与 Mac 芯片类型
- 问题发生时间和所在功能页
- 可重复的操作步骤
- 实际结果与期望结果
- 经过脱敏的错误提示或日志片段

## 请勿公开提交

- 真实工作内容、完整屏幕截图或记忆包
- 邮箱、手机号、公司内部地址等个人或组织信息
- 密码、验证码、API Key、Token、Webhook 地址或快照密钥
- 未脱敏的客户、合同、财务、医疗或其他敏感资料

如问题涉及隐私或安全，只描述必要现象和影响范围，不要在公开 Issue 中上传可识别内容。可以先提交经过脱敏的最小复现，等待维护者提供下一步处理方式。
