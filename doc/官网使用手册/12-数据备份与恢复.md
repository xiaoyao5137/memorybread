# 数据备份与恢复

备份与恢复位于 **集成 → 备份与恢复**。记忆面包遵循本地优先原则，这项能力用于在换机、重装或重要版本变更前保护记忆资产。

## 本机备份

本机备份不要求登录。

1. 打开 **集成 → 备份与恢复**。
2. 在“本机备份”中点击 **导出记忆包**。
3. 等待导出完成，记录保存路径并点击 **打开文件夹** 检查文件。
4. 将记忆包复制到受信任的存储位置。

记忆包包含时间线、知识、文档、章节、操作、本地 Skill、数据记录和来源关系等可迁移资产。原始截图不会作为可移植知识资产直接打包。

## 从本机记忆包恢复

1. 点击 **导入记忆包**。
2. 选择 `.json`、`.mbmemory` 或 `.mbsnapshot` 文件。
3. 等待导入完成。
4. 查看“新增、更新、保留本机”报告，并打开对应页面抽查结果。

导入会把备份内容与本机内容合并，不会清空或整体替换本机数据库。系统优先按业务唯一标识和内容身份判重；重复内容保留本机版本，备份中缺失的内容才新增。若不同设备恰好使用了相同的内部编号，导入时会分配新的本机编号并保持关联关系正确。

客户端设置同样以本机已有设置为准。遇到内容不同的同名本地文件时，系统保留本机文件，并将备份文件另存为带 `memorybread-restored` 标记的副本。恢复前仍建议保留当前设备的最新导出包。

## 云端备份

云端备份需要登录。记忆包会先在客户端加密后上传，每个账号默认 50MB；恢复时由客户端完成下载、校验和导入，不需要用户单独设置恢复密钥。

### 备份到云端

1. 登录记忆面包账户。
2. 点击 **备份到云端**。
3. 等待上传与校验完成。
4. 刷新云端备份列表，确认时间和文件大小。

### 恢复到本机

1. 从列表中选择目标云端记忆包。
2. 点击 **恢复到本机**。
3. 等待下载、校验和导入完成。
4. 查看合并报告，并到记忆、采集或数据页面抽查结果。

## 查看备份记录

“记忆备份”下方的“备份记录”会保留最近 100 次本机导出、本机导入、云端备份和云端导入操作。成功和失败操作都会留痕；点击一条记录可以查看导出目录、恢复目录、文件大小、输入数据行数、去重行数、实际导入行数和分项导入结果。

备份记录只保存在当前设备，不随记忆包迁移。流水中的路径仅用于帮助定位本机文件和核对恢复位置。

## 安全建议

- 只从可信位置导入记忆包，不要使用来源不明的文件。
- 在换机、重装和重大升级前分别保留一份本机备份。
- 云端备份用于可选的跨设备恢复；本机导入和导出不受登录状态影响。
- 备份完成不等于恢复验证完成。至少抽查一条时间线、一份文档和一条知识。
