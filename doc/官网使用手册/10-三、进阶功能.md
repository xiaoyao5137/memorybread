# 三、进阶功能

完成记忆面包基础的采集、记忆、咨询和创作后，可以进一步让记忆在不同工具和设备之间安全流动。

## 外部集成

适合以下需求：

- 从 Obsidian、本地文件或自定义来源导入知识
- 把选中的记忆导出到 Vault 或生成上下文包
- 为 Codex、Claude Code 安装记忆检索 Skill
- 通过自定义 Skill 定义新的输入和输出方式

集成强调可查看、可预检和可追溯。执行前可以检查 Skill 文件，执行后可以查看阶段、日志和产物。

## 数据备份与恢复

适合以下需求：

- 在本机保存一份可迁移的记忆包
- 换机或重装后恢复记忆资产
- 登录后使用客户端加密的云端备份完成跨设备迁移

本机导入和导出不要求登录；云端备份需要登录，并受账户空间限制。

## 选择建议

- 想让其他工具“使用”记忆：选择 **外部集成**。
- 想让记忆“迁移或恢复”：选择 **备份与恢复**。
- 在执行正式导入、导出或恢复前，优先使用预检、保留原文件并核对结果报告。
