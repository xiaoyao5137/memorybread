# 日记

日记用于按日、周、月回顾已经发生的工作。记忆面包会把任务生成的结果整理成可阅读、可编辑的复盘记录。

## 查看日记

1. 打开左侧 **日记**。
2. 在顶部选择 **日记**、**周记** 或 **月记**。
3. 使用日期筛选定位具体周期；需要恢复完整列表时点击 **清除日期**。
4. 从左侧列表选择一条记录，在右侧查看内容和覆盖时间。
5. 点击 **刷新** 获取最新结果。

日记通常包含工作产出、问题与解决、来源线索等内容；周记和月记还可以包含后续计划。页面会标明内容是系统生成还是经过用户编辑。

## 编辑日记

1. 打开需要修改的记录。
2. 点击右上角 **编辑**。
3. 在文本框中补充、删除或修正内容。
4. 点击 **保存**。

建议保留可验证的成果、决策和问题结论，删除浏览、搜索、应用切换等活动流水。涉及数字、负责人或截止时间时，应回到来源线索确认。

## 没有日记怎么办

日记、周记和月记由对应内置任务生成。如果页面为空：

1. 打开 **任务**，确认相应任务已启用。
2. 检查该周期是否有足够的采集和记忆内容。
3. 对任务执行一次 **立即执行**。
4. 回到日记页面点击 **刷新**。

日记适合做个人复盘和后续创作素材。需要形成正式周报或项目总结时，可以在 **创作** 中引用对应周期的记忆继续加工。
