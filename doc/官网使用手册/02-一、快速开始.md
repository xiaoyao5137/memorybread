# 一、快速开始

这份指南帮助你完成安装、系统授权、一键初始化和第一次记忆召回。

## 1. 下载正确的版本

当前官网直装版支持 macOS Apple Silicon 与 Intel 两类芯片。

- Apple Silicon：M1、M2、M3、M4 等 M 系列 Mac
- Intel：搭载 Intel 处理器的 Mac

如果不确定芯片类型，请打开 macOS 左上角苹果菜单，进入“关于本机”查看“芯片”或“处理器”。下载与当前 Mac 匹配的安装包后，按系统提示完成安装。

## 2. 完成系统授权

为了识别当前工作内容，记忆面包需要 macOS 的屏幕录制和辅助功能权限。首次启动遇到系统提示时，请前往“系统设置 → 隐私与安全性”完成授权，然后重新打开应用。

建议同时允许通知权限。初始化完成或任务产生结果时，系统可以及时提醒你。

## 3. 一键初始化

首次启动会显示初始化页面。点击 **初始化** 后，应用会自动完成必要组件、本地模型、采集提炼能力、记忆库以及咨询和创作链路的检查。

- 初始化期间请保持网络畅通。
- 可以最小化应用，初始化会在后台继续。
- 实际耗时受网络和设备性能影响，不要在下载或质检阶段强制退出。
- 某个阶段失败时，先使用页面提供的重试或恢复入口；如果反复失败，再记录阶段名称和提示信息反馈。

初始化通过后，应用会进入主界面。记忆面包坚持本地优先，本地核心能力不要求登录；登录用于账户、云端增强、加密快照等可选能力。

## 4. 检查隐私设置

开始长期采集前，打开左侧 **隐私**：

1. 确认敏感内容过滤规则已开启。
2. 将聊天、邮箱、相册、密码管理器或其他敏感应用加入黑名单。
3. 只保留与你工作目标相关的采集范围。

## 5. 完成第一次验证

1. 正常浏览或编辑一段非敏感的工作内容。
2. 等待系统完成采集与提炼。
3. 打开 **采集**，确认时间线上出现新的工作片段。
4. 打开 **咨询**，输入一个带线索的问题，例如：“我刚才看的页面主要讲了什么？”
5. 查看回答中的来源，确认它引用了正确的本机记录。

完成以上步骤，就已经跑通“采集 → 记忆 → 召回”的核心链路。接下来可以继续阅读各功能说明，或直接在 **创作** 中生成第一份工作文档。
