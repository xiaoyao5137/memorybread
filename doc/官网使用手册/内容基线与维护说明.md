# 记忆面包官网使用手册：内容基线与维护说明

本目录是官网飞书使用手册的可审计内容基线。公开页面以飞书目录为交付渠道，本地 Markdown 用于版本管理、统一术语和后续批量更新。

## 更新边界

- **产品与版本**：MemoryBread 客户端 v0.1.2，内容截至 2026-08-11。
- **公开口径**：以当前客户端用户界面、官网首页和官网演示视频为准。
- **不包含**：供应商模型名、密钥、内部成本、运营标签、调试环境和未面向普通用户发布的后台能力。
- **更新触发**：导航、功能入口、安装流程、隐私边界、备份策略或官网公开文案发生变化。

## 变更传播

先更新 `suite-manifest.json` 中的事实、术语或决策，再更新受影响的 Markdown，完成审计后同步到飞书。README 与手册共用的核心口径包括：产品定位、本地优先边界、macOS 下载范围、备份加密方式和公开反馈安全要求。

## 当前待补来源

- 官网生产域名尚未在工程中形成单一公开常量，因此手册不写未经确认的官网域名。
- 尚无对外公布的支持邮箱与安全报告邮箱，因此“联系我们”优先使用使用手册、更新记录和 GitHub Issues。
- 安装包最低 macOS 版本、硬盘空间和内存建议尚无稳定公开口径，快速开始不填写猜测值。
