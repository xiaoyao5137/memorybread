# 二、基础功能

记忆面包的基础功能围绕一条清晰路径设计：先记录工作，再沉淀记忆，随后用于咨询、创作和自动化。

| 功能 | 适合什么时候使用 | 核心结果 |
| --- | --- | --- |
| 采集 | 想找回某段工作现场或检查原始记录 | 时间线与采集记录 |
| 记忆 | 想浏览已经提炼出的长期资产 | 文档、知识、操作、数据与图谱 |
| 咨询 | 有一个具体问题，需要从过去工作中找答案 | 带来源的回答 |
| 创作 | 需要方案、总结、周报等完整文档 | 可继续修改的文档初稿 |
| 任务 | 有周期性或重复性工作需要自动执行 | 定时结果与执行历史 |
| 日记 | 想按日、周、月复盘工作 | 结构化工作日记 |
| 集成 | 需要导入外部知识或把记忆交给其他工具 | Skill 执行结果与可下载产物 |

## 推荐顺序

1. 先在 **隐私** 中确认过滤规则和应用黑名单。
2. 让 **采集** 稳定运行一段时间，积累可用的工作记录。
3. 在 **记忆** 中检查提炼结果是否准确。
4. 使用 **咨询** 完成一次有来源的召回。
5. 在 **创作** 中基于这些资料生成文档。
6. 将成熟的重复流程放入 **任务**，并在 **日记** 中持续复盘。

每个功能都可以独立使用，但数据积累越稳定，咨询和创作越容易贴近你的真实工作背景。
