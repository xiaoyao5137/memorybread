# 任务

任务用于把重复性工作交给记忆面包按计划执行，例如生成日记、项目周报、会议纪要、学习笔记或时间分析。

## 使用内置任务

任务列表默认包含日记、周记和月记等内置任务。你可以：

- 开启或关闭任务
- 编辑执行指令和执行时间
- 点击 **立即执行** 进行测试
- 查看执行历史和结果

内置日记任务可以编辑，但不能删除；用户自行创建的任务可以删除。

## 创建自定义任务

1. 打开左侧 **任务**，点击 **新建**；也可以先进入 **模板库** 选择一个模板。
2. 填写任务名称。
3. 用自然语言说明希望 AI 完成什么，并写清结果结构和质量要求。
4. 设置 Cron 执行频率。页面会显示常见表达式的解释。
5. 如需推送结果，选择已经配置的消息渠道。
6. 保存后先点击 **立即执行**，确认结果符合预期，再保持任务开启。

## 自动识别任务

任务列表底部的 **自动识别任务** 可以根据指定应用和触发词发现潜在任务。展开设置后，可维护应用 Bundle ID、应用名称和触发词。

建议先从少量、明确的应用和词语开始，观察识别效果后再扩大范围，避免产生无关任务。

## 消息渠道

任务成功结果可推送到飞书、钉钉、企业微信或通用 Webhook。渠道名称、类型和 Webhook 地址只保存在本机，不会同步到云端。

推送失败会记录在执行历史中，但不会把已经成功生成结果的任务改成失败。排查时应分别查看“任务生成状态”和“消息投递状态”。

## 常见问题

- **没有按时执行**：确认任务已开启、Cron 表达式正确，并检查应用是否在计划时间运行。
- **结果内容不稳定**：缩小资料范围，明确输出结构，并先用立即执行反复验证。
- **日记为空**：确认对应内置任务已启用，并检查该周期是否有可用工作记录。
