# 记忆面包官网使用手册文档简报

## DOC-001 — 什么是记忆面包？

- **读者任务**：理解产品定位、核心闭环和隐私边界，并决定是否继续安装。
- **依赖**：TERM-001、TERM-002；FACT-001、FACT-003、FACT-006；S1–S5。
- **信息层级**：工作记忆助手 → 采集、沉淀、使用、复用 → 本地优先的精确边界。
- **排除**：内部架构、供应商信息、定价与尚未发布能力。
- **验证**：读者能回答“它解决什么问题”和“哪些能力会联网”。

## DOC-002 — 一、快速开始

- **读者任务**：完成下载、系统授权、一键初始化和第一次验证。
- **依赖**：TERM-001、TERM-002；FACT-002；S3–S5。
- **信息层级**：选对安装包 → 完成授权与初始化 → 验证采集和召回。
- **排除**：开发环境启动、最低系统版本猜测、内部端口。
- **验证**：用户可以独立完成首次可用状态。

## DOC-003 — 二、基础功能

- **读者任务**：根据目标选择采集、记忆、咨询、创作、任务、日记或集成入口。
- **依赖**：TERM-001、TERM-003；S3、S5。
- **信息层级**：记录 → 沉淀 → 使用 → 自动化。
- **排除**：各页面的详细操作。
- **验证**：每个入口有唯一、清晰的用户任务。

## DOC-004 — 采集

- **读者任务**：在安全边界内查看、搜索和管理时间线及原始记录。
- **依赖**：TERM-001、TERM-002；FACT-003、FACT-006；S3–S5。
- **信息层级**：采集价值 → 页面结构 → 操作步骤 → 隐私与删除边界。
- **排除**：调试面板、OCR 模型实现。
- **验证**：用户知道先配置隐私，再让采集稳定运行。

## DOC-005 — 记忆

- **读者任务**：使用时间线、文档、知识、操作、数据和记忆图谱。
- **依赖**：TERM-001；S3–S5。
- **信息层级**：资产分类 → 查找与详情 → 关系与维护。
- **排除**：数据库字段和烘焙算法。
- **验证**：用户不会把原始采集与提炼资产混为一谈。

## DOC-006 — 咨询

- **读者任务**：提出可检索的问题并核对引用来源。
- **依赖**：TERM-001、TERM-002；FACT-003；S3、S5。
- **信息层级**：明确线索 → 生成回答 → 核对来源 → 继续追问。
- **排除**：模型供应商和内部路由。
- **验证**：用户知道答案是辅助材料，关键事实仍需检查来源。

## DOC-007 — 创作

- **读者任务**：从目标和真实背景出发，完成一份经过复核的文档。
- **依赖**：TERM-001、TERM-002、TERM-003；FACT-003；S3–S5。
- **信息层级**：定义交付物 → 预览参考 → 选择 Skill/Tool → 执行 → 复核。
- **排除**：内部 Agent 契约和实现细节。
- **验证**：用户不会把生成结果未经检查直接对外发布。

## DOC-008 — 任务

- **读者任务**：创建、启用、立即执行任务并查看历史或推送结果。
- **依赖**：TERM-001；FACT-005；S2、S5。
- **信息层级**：模板或新建 → 频率与指令 → 运行 → 历史与消息渠道。
- **排除**：运营奖励规则和内部任务表。
- **验证**：用户知道推送失败不等于任务生成失败。

## DOC-009 — 日记

- **读者任务**：按日、周、月查看和编辑工作复盘。
- **依赖**：TERM-001；S5。
- **信息层级**：筛选周期 → 查看结构化内容 → 编辑和保存。
- **排除**：任务调度实现和数据库结构。
- **验证**：用户知道日记来自任务结果，空白时应检查任务。

## DOC-010 — 三、进阶功能

- **读者任务**：区分外部集成与备份恢复，并选择合适入口。
- **依赖**：TERM-001；S3、S5。
- **信息层级**：让记忆流动 → 让记忆可迁移 → 安全原则。
- **排除**：基础功能重复说明。
- **验证**：用户能根据目标选择“集成”或“备份与恢复”。

## DOC-011 — 外部集成

- **读者任务**：通过可查看、可预检、可追溯的 Skill 导入或输出记忆。
- **依赖**：TERM-001、TERM-002、TERM-003；S2、S3、S5。
- **信息层级**：输入/输出分流 → 选择 Skill → 预检与执行 → 查看日志和产物。
- **排除**：未经验证的第三方平台承诺和供应商凭据。
- **验证**：用户理解导入、输出和安装编码 Agent Skill 的差异。

## DOC-012 — 数据备份与恢复

- **读者任务**：使用本机记忆包或客户端加密云端快照完成迁移和恢复。
- **依赖**：TERM-001、TERM-002；FACT-004；S1、S2、S5。
- **信息层级**：选择备份方式 → 执行备份 → 执行恢复 → 核对导入报告。
- **排除**：服务端供应商、密钥材料和内部对象键。
- **验证**：用户知道云端备份需要登录，本机导入导出不需要。

## DOC-013 — 四、联系我们

- **读者任务**：选择渠道并提交不含敏感信息的可复现反馈。
- **依赖**：TERM-001；FACT-001；S2、S3、S5。
- **信息层级**：自助检查 → 选择渠道 → 提供必要信息 → 脱敏。
- **排除**：未确认的邮箱、群号和响应时限承诺。
- **验证**：公开反馈不包含真实工作内容、截图、密钥或记忆包。
