# 创作

创作用于基于真实工作背景生成可继续修改的文档。记忆面包会按目标召回本机资料，并通过创作 Agent、Skill 和 Tool 完成结构设计、撰写与检查；本地优先是默认边界，采集、提炼、检索与创作默认在本机完成。

## 创建一份文档

1. 打开左侧 **创作**，点击 **新会话**。
2. 说明交付物、读者、时间范围和关键要求，例如：“基于本周项目记录，生成给管理层的研发周报，突出交付、风险和下周计划。”
3. 点击 **预览参考**，检查本轮准备使用的记忆和数据是否相关。
4. 需要固定结构或专业流程时，选择已安装的 Skill；需要检索、数据或画图能力时，确认相应 Tool 已启用。
5. 开始创作，并在右侧 **执行过程** 中查看各阶段状态。
6. 完成后核对正文、来源和数据，再复制或继续对话修改。

## 四个常用入口

- **创作**：当前文档与 Agent 对话。
- **创作记录**：查看过去的会话和生成结果。
- **技能**：安装、编辑和管理可复用的创作 Skill。
- **工具**：管理互联网检索、记忆搜索、数据检索、网页读取和画图等能力。

## Skill、Tool 与 Agent 的区别

- **Skill**：定义某类文档的目标、结构、规则和执行步骤，适合稳定复用。
- **Tool**：提供检索、读取、数据或画图等单项能力。
- **Agent**：理解目标、选择已允许的能力并组织最终文档。

## 写好创作指令

建议一次写清：

- 要生成什么文档
- 读者是谁、需要做什么决定
- 资料时间范围和项目范围
- 必须包含或禁止出现的内容
- 期望长度、语气和格式

如果资料预览不准确，先修改线索或时间范围，不要直接开始生成。正式对外发布前，应人工检查事实、数字、链接、隐私信息和承诺性表述；AI 生成的初稿不是自动批准的最终版本。
