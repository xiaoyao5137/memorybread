# 记忆

记忆页展示从工作记录中提炼出的长期资产。它关注“以后还能怎么用”，而不只是保留一张截图或一段历史。

## 记忆资产类型

- **总览**：查看文档、知识、操作和数据的数量与变化。
- **文档**：可复用的文档模板、结构和内容样本。
- **知识**：事实、概念、结论和判断，适合咨询时召回。
- **操作**：解决某类问题的步骤、注意事项和 SOP。
- **数据**：带来源和采集时间的指标、表格或报表快照。
- **记忆图谱**：根据共同来源或显式引用展示不同资产之间的关系。

## 查找和查看记忆

1. 打开左侧 **记忆**。
2. 先在 **总览** 判断当前积累情况，再进入对应资产类型。
3. 使用关键词或筛选条件缩小结果。
4. 选择一条记录，查看摘要、详情、来源时间线和关联资产。
5. 对重要内容进行编辑、补充或沉淀为更适合复用的形式。

数据类记忆会保留来源网址、采集时间和快照关系。需要最新数据时，可在支持的来源上执行即时刷新；登录态网页会在原浏览器安全上下文中读取，Cookie 不会保存到记忆面包。

## 使用记忆图谱

打开 **记忆图谱** 后，可以搜索主题并查看知识、文档、操作、数据与来源之间的连接。选择节点即可查看详情或跳转到对应资产。

图谱用于发现关系，不代表所有连接都具有因果含义。关键判断仍应回到来源记录核对。

## 维护建议

- 优先保留有明确来源、能解释“为什么”的记忆。
- 对重复或过时内容及时清理，避免咨询时召回相互冲突的版本。
- 删除提炼资产不会自动删除来源时间线和采集记录；不同层级需要分别管理。
- 为高频文档保留稳定模板，为重复问题沉淀操作手册。
