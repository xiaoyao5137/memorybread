# 外部集成

外部集成让记忆面包与知识库、编码 Agent 和自定义工作流连接。所有集成都以 Skill 为边界：你可以查看 Skill 文件、检查输入、预检影响并查看执行历史。

## 三类入口

- **输入**：把外部文件或知识整理后写入本机记忆。
- **输出**：选择本机记忆，生成上下文包、导出到知识库或安装编码 Agent Skill。
- **备份与恢复**：导出、导入或恢复完整记忆包。

## 执行一个集成 Skill

1. 打开左侧 **集成**，选择 **输入** 或 **输出**。
2. 选择一个内置 Skill，点击 **文件** 查看说明和源码。
3. 点击 **执行**，按 Skill 要求选择文件、文件夹、记忆条目或输入查询线索。
4. 如果 Skill 支持，先点击 **预检**，确认计划创建、更新、覆盖或跳过的内容。
5. 确认无误后正式执行。
6. 在右侧查看阶段、结果、逐条日志和可复制、可下载的产物。

## 常用场景

### Obsidian

- 输入：读取 Vault 中的 Markdown 内容并整理为本机记忆。
- 输出：选择记忆条目和目标 Vault，将内容写入指定子目录。

正式导出前建议先预检覆盖数量，并对 Vault 做版本控制或备份。

### Codex 与 Claude Code

安装 `memory-retrieval` Skill 后，编码 Agent 可以按任务需要访问记忆面包的本机只读召回服务。默认只返回少量相关片段，不会一次性发送全部记忆。

被选中的片段会进入当前 Agent 会话，因此仍应根据所用模型和会话的隐私策略决定是否调用。

### 自定义 Skill

可以上传包含 `SKILL.md` 的自定义 Skill 包。上传前请检查来源和文件内容；不要在 Skill 中写入密钥、密码或不可审计的外部上传逻辑。

## 本地边界

记忆面包遵循本地优先原则。文件读取、记忆查询和受支持的 Skill 执行通过本机服务完成；页面会明确展示外部输出目标。任何需要把内容发送到第三方的自定义流程，都应在执行前由用户确认范围和目的地。
