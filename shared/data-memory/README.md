# 数据记忆与数据 Tool 契约

`data-tools.schema.json` 定义 MemoryBread 本地“数据”资产以及创作 Agent 可调用的两个稳定 Tool。

## 稳定 Tool ID

| Tool ID | 职责 | 隐私边界 |
| --- | --- | --- |
| `data_search` | 从本地数据模块召回数据源、最近快照、时效评分和来源证据 | 只读取本机 SQLite；事件中不返回原始正文 |
| `webpage_scrape` | 对 `data_search` 选中的数据源执行按需刷新 | 优先复用现有浏览器登录会话；不读取、复制或保存 Cookie |

日报、周报、项目总结和数据分析类任务可先用 `data_search` 探测是否存在相关数据，但不预置固定后续链路。所有候选（包括报表 URL）进入同一 Top-K 排序，不为 URL 预留名额；规范 URL 完全相同、标题完全相同只作为高强度相关性信号。同一站点中 `dashboardId + sheetId` 相同的编辑、预览、Tab、筛选器和图表 URL 视为一个逻辑看板，只保留最适合采集的预览/Tab 入口，不能重复打开多个历史链接。Top-K 形成后，Harness 对其中的报表 URL 追加 `webpage_scrape`，在本轮创作中重新取数并生成截图证据；存在通过截图校验的报表数据或可分析工作快照时才追加 `data_analysis_agent`。

`data_search` 单次默认召回 30 条，用户可在创作“工具”页配置 1～50 条；配置随本机工具设置保存并随每次创作请求传入，旧客户端不传时仍按 30 条执行。

## 数据来源与时效

- `report_url`：报表、看板、监控和分析平台地址。默认 `refresh_policy=on_demand`、`access_mode=browser_session`，需要最新数据时不得只采用过期快照。
- `work_memory`：从文档、工作 IM、时间线和采集正文识别出的数据陈述。其事实时间未知时以 `observed_at` 作为时效下界，并随采集时间衰减。
- 工作数据必须同时具有数值和可命名的指标、对象或统计维度，并能独立回答“什么对象的什么指标、值是多少”。百分号或金额、资源等单位只表示值的形态，不能替代指标含义；`9类 43%`、`7类33%` 等孤立数字直接丢弃。日期、时刻、版本号、计划规模、参与人数、文件变更数、导航数量、评论计数，以及只出现“用户”“客户”“数据”等泛词的界面正文不是数据；人数、条数、集数和普通时长等通用量纲本身也不足以构成数据。候选句超过 280 字符或命中明显界面噪声时直接排除。
- 新采集的工作数据使用 `timeline-data-fact.v3` → `data-memory.v15` 模型提炼链路。模型在生成时间线的同一次调用中直接输出 `data_facts`，完整保存对象、动作、目标场景、比较维度、指标、值、独立事实句和原文证据；例如“生服模特库在电商 AIGC 中复用节省成本”不会再被后置规则缩成“AIGC 成本”。套餐与版本数据必须保留按年/按月、Standard/Plus 等关系，检查清单、预案和验收阈值不得伪装成实测结果。已经实际执行的生成参数、完成任务耗时和验收结果属于观测事实，但必须恢复具体产品、任务或目标场景；仅有“参数配置/生成控制”等执行壳会被拒绝，明确包含业务对象的“MemoryBread 官网首屏视频参数配置”仍属于具体场景。`16分31秒` 等复合时长作为一个完整值保存。Sidecar 优先将模型改写的引文重新对齐到原采集文本；只硬性要求数值与至少一个对象/场景/指标锚点可逐字回证。未回证的单位、维度或展示对象会被清空或降级到已回证锚点，不再因次要字段整条丢弃真实数值。若模型把同批多个原子事实写成同一句汇总，Sidecar 会把不包含当前语义锚点和值的 `statement` 规范化为当前事实句；Core Engine 的 `fact-specific.v1` 渲染再以结构化摘要和逐字证据生成快照正文，避免多个数据记录展示成同一内容。提炼结果与成功/拒绝计数写入独立规范表。
- 主时间线提炼遗漏或拒绝全部数据事实、但原始采集仍有强数值与指标信号时，Sidecar 在同一处理任务内只追加一次聚焦补提炼；工作语境只能补全标题、动作和目标场景，逐字证据仍必须来自原采集。同义句与重复截图按语义键去重。Rust 对 `timeline-data-fact.v3` 只校验字段长度、枚举、对象/指标/数值完整性和证据可回查性，然后进行确定性归一化、去重、快照落库；v3 即使零事实也不会回退旧解析器“猜”出另一套宽泛语义。历史 v1/v2 继续保持兼容读取。`semantic_origin=model_structured_fact` 可用于审计这条路径。
- 历史时间线没有 `timeline-data-fact.v1/v2` 运行记录时继续使用只读兼容解析器，并标记 `semantic_origin=legacy_parser`。兼容解析仍要求数据能够独立回答“什么对象的什么指标、值是多少”，但不再用于任何新提炼结果。
- `data_sources` 保存稳定数据项与刷新策略；工作数据只以稳定页面/文档范围和规范化后的“显式对象 + 指标集合”共同判重，不使用原始标题片段、动作谓词或仅由宽泛上下文猜出的对象。同一页面中同一语义的新采集只在同一自然周阶段内更新同一条 `data_snapshots`；跨周采集创建新快照，较旧历史回填不能反向覆盖同阶段的较新值。无法识别稳定页面范围的通用聊天窗口保持时间线隔离，避免误合并不同话题。`data_source_links` 保留所有 capture/timeline 来源关系。
- 后台识别首批从最新采集开始；后续批次为新增记录保留主要预算，并用剩余预算持续向历史记录回填。游标只记录采集 ID，不保存正文或 URL。
- 下一轮数据识别会分批把历史 v1-v14 快照持久化重建为 v15。历史记录保持兼容解析并保留来源关联；新契约事实直接沿用模型标题和独立事实句，不再被历史规则重新命名。历史源只有在同一时间线内同时命中完整值与指标语义时才会升级或合并，单纯同值不构成匹配，不能用另一条事实覆盖同时间线中的不同指标；一条旧事实拆成多条具体事实时优先复用语义匹配的相邻旧 ID。画幅、宽高等 `16:9` 或 `16：9` 冒号比例属于合法比例值。无法回证、缺少对象或指标、指标与单位冲突的数据不会生成有效视图。未采集报表通过单独的 `pending_items` 返回，不占用数据记录的页容量。
- 数据详情展示本地数据 ID 和来源时间线，并支持软删除数据来源；删除不会删除时间线或采集记录，自动识别也不会自行恢复已删除的数据。

## 网页采集策略

1. 登录态或内网报表优先附加来源浏览器或其他正在运行的受支持浏览器。当前支持 Google Chrome/Canary、Microsoft Edge、Brave、Chromium、Vivaldi 和 Safari。
2. 普通手动刷新在后台临时标签读取 DOM。创作证据模式使用独立的后台浏览器窗口：窗口加载和截图期间保持在用户当前应用之后，不切换用户现有窗口或标签；Core Engine 以窗口标题/边界精确匹配后截图，并把运行中缩略图通过本机只读地址展示在创作轨迹中。完成或失败后关闭专用窗口并核对前台应用未变化。没有浏览器进程时可后台启动已安装的 Chromium 浏览器，任务结束且没有其他窗口时退出。
3. 浏览器通道不可用、页面不依赖登录态时，普通刷新可降级为直接 HTTP 抓取；但创作截图必须来自浏览器实际渲染，因此证据模式不以 HTTP 文本代替截图。Firefox、Arc 等尚无 Apple Events DOM 适配器的浏览器当前只能使用公开页面 HTTP 通道，不能生成创作截图证据。
4. 只允许 `http`/`https` URL；不执行页面提供的脚本指令，不持久化 Cookie、Authorization header 或浏览器配置。
5. 页面正文和结构化表格覆盖本机最新数据快照；截图保存到本机创作证据目录，归属 `run_id`/`session_id`。可选 `preview_id` 为 UUID，运行中预览与最终证据共用该文件标识；预览端点禁止缓存且只读取该 UUID 对应的 JPEG。图片不与会被覆盖的数据快照强绑定，也不进入加密资产快照。
6. `objective`、`expected_period_start/end` 和 `requested_metrics` 逐字来自当前 Skill 步骤；旧字段 `required_metrics` 仅作兼容别名。采集器按目标选择指定 Tab、填写本周日期范围，并对页面主滚动区或看板内部横纵滚动容器分段取数和拼接截图；不能只读取首屏可见区域。
7. SPA/BI 页面在网络加载完成后继续轮询当前视口内可见的加载节点与正文稳定性；每次长页滚动后都重新等待当前分段，再提取文本和截图。隐藏 Tab 的占位文字不阻塞当前页面；达到上限仍有局部加载节点时保留已就绪内容交给逐项校验，不误报为“页面无数据”。
8. Sidecar 对截图执行 OCR，并将 OCR 与同次 DOM/表格中的指标标签和数值逐项比对，同时核对 URL、标题、采集时间和统计周期。`requested_metrics` 按指标独立判定：可用几项就展示几项，其他项缺失或周期不相容不会拒绝整个采集任务，也不会生成“数据未获取”、“数据未明确区分”等占位值。Canvas 图表允许以截图 OCR 提取数值，但单项数值必须满足 OCR 置信度阈值、指标名能在同次 DOM 中得到语义支持且该指标附近无加载遮罩。只有通过的数值才进入写作环境；截图证据卡只插入实际使用该数值的段落或表格下方。
9. 文档默认展示围绕已采用指标裁出的聚焦截图；原始全图按内容哈希保留并提供审计入口。对拼接截图只使用最终图像坐标系中的 OCR box 生成聚焦裁剪，不把各滚动分段的 DOM 坐标直接混用。

直接 HTTP 不读取浏览器会话。登录态通常不只依赖 Cookie，还可能依赖系统钥匙串加密、`localStorage`、临时令牌、SSO 跳转、客户端证书和页面 JavaScript 请求；复制这些凭据既不可靠，也会扩大泄露面。因此 HTTP 通道只用于无需登录的页面，登录态/内网页面交给浏览器在原安全上下文中加载。

## 稳定错误码

| 错误码 | 含义 | 可恢复方式 |
| --- | --- | --- |
| `DATA_SOURCE_NOT_FOUND` | 数据源不存在或已停用 | 重新执行数据识别或选择其他来源 |
| `DATA_SOURCE_URL_MISSING` | 数据源没有可刷新的网页地址 | 使用已有工作记忆快照 |
| `BROWSER_ATTACH_UNAVAILABLE` | 没有受支持浏览器正在运行，或系统自动化权限不可用 | 打开已登录的受支持浏览器并授权 MemoryBread 控制 |
| `BROWSER_SCRIPTING_DISABLED` | 浏览器禁止 Apple Events 执行 JavaScript | 开启对应浏览器的 Apple Events JavaScript 设置 |
| `SCRAPE_AUTH_REQUIRED` | 页面落在登录/鉴权页 | 在对应浏览器完成登录后重试 |
| `SCRAPE_NOT_FOUND` | 页面或文件已不存在 | 停止保存错误快照，等待新的有效来源链接 |
| `SCRAPE_EMPTY` | 页面没有可用正文或表格 | 检查页面加载状态或改用其他来源 |
| `SCRAPE_FAILED` | 两种采集通道均失败 | 保留旧快照并展示采集时间 |
| `EVIDENCE_CONTEXT_REQUIRED` | 创作截图缺少运行或会话身份 | 由 Creation Harness 补齐 `run_id`/`session_id` 后重试 |
| `SCREENSHOT_FAILED` | 页面已读取但浏览器窗口截图失败 | 检查系统录屏权限后重试 |
| `EVIDENCE_VALIDATION_FAILED` | 截图 OCR 与 DOM/表格或页面元数据不一致 | 不采用当前数值，改用其他证据或人工核验 |
| `DATA_SEARCH_UNAVAILABLE` | 本地数据索引暂时不可用 | Agent 基于其他记忆继续并标记数据缺口 |

## 兼容规则

- `data_search` 与 `webpage_scrape` 属于必备创作 Tool。旧客户端不传 `enabled_tools` 时，Core Engine 与 Sidecar 自动补齐。
- 新 Tool 只在 Harness 判断任务需要数据证据时进入候选计划，不影响普通创作的执行步数；`webpage_scrape` 与数据分析 Agent 是否执行由前一步反馈动态决定。
- 未识别字段必须被兼容读取方忽略；契约新增字段默认保持可选。

## 阶段历史

- 数据与知识、文档、操作不同：同一对象和指标不会永久覆盖，只在同一自然周内鉴重更新。
- 每条快照携带 `period_granularity=week`、`period_key`、`period_start_at` 和 `period_end_at`；`structured_data.period` 与 `provenance.period` 同步保留阶段标签。
- `data_search.results[].history` 按阶段倒序返回历史快照。创作与咨询在做趋势、环比或历史值分析时必须使用这些阶段标签，不能只引用最新值。
