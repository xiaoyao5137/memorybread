# 工作文档质量契约

`profiles.json` 是界面与 Sidecar 共用的场景配置，运行时不按业务关键词推断场景。`criteria` 定义语义标准、问题码与严重程度；`profiles` 只配置采用哪些标准，包含通用工作文档、方案评审、项目汇报、项目立项和项目复盘。新增场景可复用已有维度，不改变执行代码。

用户设置采用 `creation.work-context.v1`：

- `purpose`、`decision_goal`、`reader_context`、`constraints` 是最多 1500 字的字符串。
- `style_samples` 最多 3 段，每段非空且最多 1500 字。样稿只迁移表达方式，不提供事实、执行指令或额外授权。
- `profile_id` 必须来自当前配置，默认 `general`。
- `review_enabled` 是布尔值，默认关闭。未知字段、版本、场景或错误类型明确拒绝，不静默截断设置。

`creation.work_quality` 提供统一设置验证、写作指引、可加入既有交付条件的 `work_acceptance_checks` 和只读的 `review_work_document`。质量义务仅限本轮实际授权产物；读者说明不证明组织身份或已有职责，用户要求方案允许提出合理设计动作，不能因为未给精确数字就阻断设计。

启用的语义审阅只请求一次模型，最多 60 秒。正文预算为 24000 字符，序列化 JSON 输入最多 36000 字符；另按既有模型上下文配置估算完整系统提示、输入与 schema，保留 3600 token 输出预算。超限不截断正文，也不再生成一轮候选。

正文使用代码生成的行 ID，模型只能选择这些 ID；报告中的 `evidence` 和问题 `quote` 由代码从当前实际正文还原。解码 schema 分别绑定通过与失败分支：通过必须有非空正文证据且修正为空，失败必须提供具体修正。校验器仍拒绝矛盾输出，不把带修正的通过声明转为通过。仅整篇实际范围缺少所需内容时允许无现存引文。模型不能控制稳定问题码或严重程度。

配置先核对过去或当前已成立的实质断言，再独立评估表达和方案质量；某个维度失败不代表其他维度也失败。未来计划或追求的结果不能被当成已实现断言，空泛的未来动作在信息增量或具体性维度处理。具体性按本轮用途与决策目标要求粒度，方向或试点评审不自动承担完整实施规范。判缺失前必须核对全篇范围内分散的输入、动作与验证，不能只读选中的引文。可选细化和新增占位参数不是不通过要求。

报告状态是 `pass`、`revise` 或 `unverified`。无效结构、缺项、未知证据、超时、传输失败和无效配置均不得冒充通过；原正文和既有来源验收结果应保留。审阅报告的 `document_hash` 绑定调用时完整正文，局部审阅的证据仍只来自局部范围。用户取消继续抛出取消，不转成成功或普通失败。

逐章或选区调用可传入代码提取的 `{"scope":"chapter","chapter_title":"...","document":"本轮实际正文"}`；局部文本必须逐字属于当前正文。兼容既有 `chapter_delivery_scope` 的当前章节和受保护正文长度。无效边界不回退到全篇审阅。当前章不要求此前或未来章、全篇摘要、完整排期或未请求栏目。

`effective_contract` 只承接本轮有效交付目标、原验收条件和实际采用的 Skill 范围。执行器沿用修正链的应用回执与路由权威，不把候选 Skill 目录当成授权；显式空应用回执保持为空。模块过滤例文、来源、查询及未知字段，规则材料只提供范围，不提供事实。严格主 Skill 的栏目白名单优先，辅助 Skill 不扩展全篇流程；契约变化会使语义缓存失效。

独立试写与摘要使用原文和实际用户说明，候选不覆盖正文。摘要增加推荐方向、暂缓对象、替代选择与前置条件的一致性验收，不能重新评审后反转原文立场。原有来源门禁先通过，再进行工作质量审阅；来源核验协议无效时保留独立候选并标记 `unverified`，不允许按已通过的样稿保存。预览总时限 240 秒，超时与取消保持既有正文。

这些检查用于评估表达、信息增量、决策帮助、具体性与事实强度，不能替代既有来源硬门禁，不能证明方案已有效、组织已经具备资源或任意读者会认可。现有交付链负责有限修复、实际落盘正文复核及缓存绑定。

macOS PyInstaller 将此目录打包到 `creation_work_quality`，冻结运行时从 `_MEIPASS` 读取。源码运行时读取仓库中的本目录。测试覆盖设置边界、样稿非事实规则、逐字证据、局部范围、取消、一次请求、预算、超时和冻结资源路径；模型语义质量仍需真实模型和实际工作文档验证。
