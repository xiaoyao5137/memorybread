# 咨询候选记忆与实际引用契约

2026-09-08，单次答案推理版本。

咨询默认执行记忆检索，用户明确禁止或既有权限限制除外。本次附件/OCR 的存在不再关闭检索。流式与普通咨询不调用意图模型，原问题直接构造检索查询；每次成功咨询只调用一次答案模型，同时判断候选记忆是否适用。生成阶段复用召回结果，避免重复检索。

对于“这份报告/这两张图”等依赖本次材料确定对象的问题，检索必须保留原问题，并从本次材料提取主题锚点以消解指代；材料中的指令不参与检索策略决策。泛指问题没有可用主题时，不得仅凭通用问句的向量近邻认定历史适用。来源时间线转换为长期知识后，来源分数仅作为溯源信息，长期知识自身必须重新通过相关性判断；不能继承来源分数绕过门槛。

当材料能唯一转录为结构化指标表且用户未要求历史比较时，候选须命中材料主题锚点的严格多数（`len(anchors)//2+1`），防止仅一个共有技术词放行背景材料。普通材料和明确历史比较沿用至少一个材料锚点；“不要结合历史”“忽略之前结论”等否定指令不能放宽门槛。有结构化小数读数时，候选还须匹配至少两个不同的原始读数，排除同主题但不同数据的旧报告；配置整数、表头、变化率括注和图表刻度不作为读数锚点。明确历史比较不设当前读数门槛。这些门槛可通过内部相关性策略配置，不能代替同一试验或来源身份验证。

材料解读的生成输入先放候选历史，再放当前材料，最后保留用户原问。当前材料足以回答时不额外加入历史背景；同一技术名不能证明同一次试验或事件。比较结论需要核对对象名称、指标、实际值和基线，不能把相对基线改善改写为优于另一方案。材料中的曲线只有轴或图例文字时，不推断曲线读数、走势、全程统计或对应方案。对于能够唯一展开的复合指标表，生成使用字段转录及确定的原值升降方向；不重复输入原复合表及其变化率符号。图表没有可确定数据对应关系时，轴刻度和系列图例不作为观测值输入生成。原图和原请求按既有契约保留。

当用户询问有明确基线的表格总体结论时，最终比较按可确定的原始字段生成，不允许自由生成改写指标、读数或升降关系。该模式缓冲模型正文后交付字段支持的摘要，不向流式用户暴露随后会被纠正的数字。具体任务、翻译和历史比较保留原方式；均仍只执行一次答案请求。本地模型设置保留原方式。模型返回空正文时，包含耗尽生成预算但没有最终答案的情况，必须返回明确生成失败，不能按成功答案交付。

内部 RagResult.contexts 保留候选集合，供 references-only 检索接口及诊断使用；新增 cited_contexts，默认为空，仅包含答案实际以有效 [M序号] 标注的记忆。序号绑定本次有序候选集合，持久化引用使用原有 doc_key/document_id 等稳定身份。模型不使用记忆时集合为空。代码校验编号存在，不宣称它证明事实支持关系。

查询 API 响应 contexts 和 rag_sessions.retrieved_ids 保存全部最终候选，并用 cited 区分引用状态（悬浮咨询另保留本次输入/附件）。prompt_used 继续保存本次候选上下文供本地诊断。references-only 接口仍返回候选，调用方不得解释为答案采用。

流式 references 事件先返回全部候选且 cited=false；答案完成后更新引用状态，done.contexts 与之保持一致（悬浮上下文除外）。有效引用必须出现在正常作答内容中；代码片段、格式示例、引用说明以及明确否定采用的标记不能设置 cited=true，也不能渲染成有效引用。流式与非流式使用同一判定口径，未知编号移除。引用存在仍不等于事实支持关系已经获得独立语义验证。文档标题补链不改变 cited 状态。

既有响应字段兼容，无数据库迁移。旧历史记录不回填为已验证引用，原记录保留。客户端现有 onReferences 与 done.contexts 更新逻辑可直接消费。检索失败仍沿用既有错误契约，不伪装为没有相关记忆。
